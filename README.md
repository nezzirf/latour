# Soen : L'Épreuve de la Tour

Jeu de plateforme quotidien en un seul fichier (`index.html`) : ouvre-le dans un navigateur pour jouer.

- Le sorcier Chronos a emmené notre chien tout en haut de sa tour : grimpe les 12 étages pour le sauver.
- Une tentative par jour, 30 minutes de chrono, un thème différent chaque jour de la semaine (20 variantes qui tournent).
- Contrôles : ⬅️ ➡️ (ou Q/A · D) pour bouger, Espace ou ⬆️ pour sauter (2× = double saut), P pour la pause.
- Manette Nintendo Switch (Pro Controller ou Joy-Con, connectée en Bluetooth à l'ordinateur) : stick ou croix pour bouger, A/B/X/Y pour sauter, ⊕ pour la pause ; dans les menus, croix pour choisir, A pour valider, B pour revenir.

Le design utilise Tailwind et le chien 3D utilise three.js, tous deux chargés depuis internet. Hors ligne, le jeu reste jouable avec un chien dessiné.
